# 牛马状态测试

一个微信小程序，用轻量测试帮助用户从工作、情绪、性格和两性关系四个维度做一次自我觉察。

## 功能

- 工作性价比：根据收入、工时、通勤、福利与工作环境估算真实时薪和工作价值。
- 情绪监测：通过 12 道题梳理当前情绪负荷，并提供自我照顾建议。
- 性格测试：生成工作性格类型与通俗易懂的性格倾向说明。
- 两性关系：从沟通、信任、陪伴与亲密四个维度形成关系自查报告。
- 首页倒计时：展示下一次周末与法定假期的倒计时。
- 结果分享：各结果页均可生成黑白风格报告图片，并调用微信图片分享能力。

## 本地开发

1. 使用微信开发者工具导入本项目目录。
2. 选择小程序 AppID（或使用测试号）并编译预览。
3. 使用手机微信预览时，可测试生成报告图片后的分享能力。

项目使用原生微信小程序技术栈，无需安装 npm 依赖。

## 项目结构

```text
pages/
  index/             首页
  work-value/        工作性价比表单与报告
  emotion/           情绪监测问卷与报告
  personality/       性格测试问卷与报告
  quiz/              两性关系问卷
  result/            两性关系报告
utils/
  mbti.js            MBTI 内容与分析逻辑
  share-poster.js    分享报告图片生成工具
assets/images/       图片资源
```

## 数据与隐私

- 测试答案与表单内容仅保存在用户设备本地，用于生成本次结果，不会上传到服务器。
- 分享功能会生成一张本地临时报告图片，并通过微信的图片分享菜单发送。
- 测试结果仅供娱乐，不构成心理、医疗、法律或关系决策建议。

## 注意事项

- 图片分享能力需在手机微信中测试；微信开发者工具不支持完整的好友或朋友圈分享流程。
- `project.private.config.json` 是本地微信开发者工具配置，已通过 `.gitignore` 排除。
